# Prompt Library 可重用 PPT 模板 / Reusable PPT templates

## 繁體中文

這兩份模板的版面、文字與視覺設計由 `junru-norple` 建立，標示為 `PUBLIC_REUSABLE_TEMPLATE`，不是任何第三方的官方模板。

- 橫式：16:9，含封面、內容、圖片、結尾 4 種可編輯頁型。
- 直式：9:16，含封面、內容、圖片、結尾 4 種可編輯頁型。
- 字體策略：拉丁標題優先 Aptos Display；繁中正文使用 Microsoft JhengHei，缺字時交由 PowerPoint 系統 fallback。
- 使用方式：下載的 ZIP 內含 PPTX、python-pptx 完整 MIT License、雙語 attribution、授權範圍與 Artifact Manifest。

## English

The layout, copy, and visual design were created by `junru-norple` and are marked `PUBLIC_REUSABLE_TEMPLATE`; they are not official templates of any third party.

- Landscape: 16:9 with editable cover, content, image, and closing layouts.
- Portrait: 9:16 with the same four editable layout roles.
- Font strategy: Aptos Display for Latin headings and Microsoft JhengHei for Traditional Chinese body text, with PowerPoint system fallback.
- Distribution: the downloadable ZIP carries the PPTX, the full python-pptx MIT license, bilingual attribution, scope, and an artifact manifest.
