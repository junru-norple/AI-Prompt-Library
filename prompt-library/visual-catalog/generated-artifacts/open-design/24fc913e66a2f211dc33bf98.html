Principles · 5 Rules
Principles
Five rescue principles, applied room by room. Each one is independently useful, but every one answers to the same test: does the visitor understand the argument before they read a single wall label?
Rule · Title · Detail
01

One thesis, no sub-themes

State the argument in one sentence and cut every pavilion proposal that doesn't serve it, no matter how strong the individual work.

02

One question per room

Each room answers a single visitor question before it raises a new one — never two arguments sharing a wall.

03

Wall text earns its place

Didactic copy stays under 40 words per work; the piece argues, the label only confirms what the eye already found.

04

Sightline before label

Design the walk before the words: the visitor's eye must find the work first, the text second, every time.

05

End on commission, not survey

Close each wing with a newly commissioned work — never a retrospective clip show of editions past.

03 / 08
Second Chapter — The Room System
02
Nine rooms, one continuous argument

The old floor plan sprawled across 22 rooms with no fixed walk order, so every visitor built a different thesis by accident. The rebuild collapses it to nine rooms on a single locked walk: each room inherits the thesis, answers one question, and hands the next room its opening line.
