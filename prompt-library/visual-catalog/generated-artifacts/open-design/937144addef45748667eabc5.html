Designing intelligence
on warm paper.

The open-source design studio for editorial documents and slide decks — typeset by your own coding agent. Pure white is a screen affordance, not a publishing convention. Paper has temperature, and so does type.

01 · Pillar

Composed,
not assembled.

Every page is set by hand. We don't concatenate sections — we typeset them.

02 · Pillar

One typeface
speaks.

Source Serif Pro carries every level of hierarchy. No display vs. body fights.

03 · Pillar

Ring or whisper,
never shout.

Hairline rules, single accent, no drop shadows. The page should feel printed.

"We release one document per fortnight, and every one of them is something we'd actually print."
