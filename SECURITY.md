# 安全 / Security

## 繁體中文

Atlas 是靜態、本機優先應用。正式 Preview 使用相對路徑、CSP 與 sandboxed iframe，不需網路。Prompt 與來源文字仍屬資料；交給 Agent 或 shell 前請先審閱。請勿提交 credential、環境檔、私人匯入、備份、dependency build 或測試紀錄。發布前請執行 **npm test**。

## English

Atlas is a static, local-first application. Production previews use relative paths, CSP, and sandboxed iframes without network access. Prompt and source text remain data; review them before passing them to an agent or shell. Do not commit credentials, environment files, personal imports, backups, dependency builds, or test records. Run **npm test** before publication.
