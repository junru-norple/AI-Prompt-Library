# 隱私與發布邊界 / Privacy and Publication Boundary

## 繁體中文

本 Repository 由 allowlist-first／default-deny pipeline 產生。只包含已確認再散布依據、固定來源版本且具完整可用內容的公開項目與第一方原創套件；私人匯入、封存、備份、內部雜湊、來源電腦路徑、測試證據及未核准來源均不包含。公開 Manifest 只描述公開成品本身。

稽核能證明目前沒有已知阻塞，但不能保證網際網路、第三方快取或既有 clone 從未保留舊內容。發現疑似敏感資料時，請不要複製其值，僅回報檔案、類別與可重現步驟。

## English

This Repository is produced by an allowlist-first, default-deny pipeline. It contains only fixed-version, complete and usable public entries with a confirmed redistribution basis, plus first-party packages. Personal imports, archives, backups, internal hashes, source-machine paths, test evidence, and unapproved sources are absent. Public manifests describe only the public artifact itself.

The audit can establish that no known blocker remains in the current artifact; it cannot prove that an earlier public copy, third-party cache, or clone never retained old material. If suspected sensitive data is found, do not reproduce its value—report only the file, category, and reproducible steps.
